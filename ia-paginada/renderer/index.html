Como funciona

        
Igual a uma impressora que imprime um livro página por página: o modelo é montado
          vazio (sem ocupar memória). Quando a camada N vai rodar, só os pesos dela são lidos do
          disco para a GPU/CPU; ao terminar, são descartados e a camada N+1 entra. Enquanto uma camada
          roda, a próxima já está sendo lida em segundo plano. Assim cabe um modelo de 70 GB numa
          GPU de 8 GB — mais devagar, mas funciona.
